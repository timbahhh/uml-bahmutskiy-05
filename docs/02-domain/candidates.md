# Кандидаты в классы

| Существительное из сценария | Решение | Почему |
|---|---|---|
| Пользователь | Класс | Имеет уникальный идентификатор, личные данные и жизненный цикл учётной записи |
| Учётная запись | Класс | Хранит данные авторизации и имеет собственное состояние |
| Чат | Абстрактный класс | Объединяет общие свойства личных и групповых чатов |
| Личный чат | Класс | Имеет собственную идентичность и связывает двух пользователей |
| Групповой чат | Класс | Имеет название, список участников и собственный жизненный цикл |
| Сообщение | Класс | Имеет автора, содержимое, время отправки и статус доставки |
| Текст сообщения | Атрибут Сообщение.содержимое | Не имеет отдельной идентичности и жизненного цикла |
| Получатель | Роль класса Пользователь | Получателем сообщения выступает существующий пользователь |
| Отправитель | Роль класса Пользователь | Отправителем сообщения выступает существующий пользователь |
| Статус присутствия | Перечисление PresenceStatus | Имеет ограниченный набор значений: онлайн и офлайн |
| Статус доставки | Перечисление DeliveryStatus | Описывает состояние доставки сообщения |
| Подключение | Атрибут Пользователь.статусПрисутствия | В рамках данной модели отдельный объект подключения не требуется |
| Сервер | Не моделируем | Это инфраструктурная часть системы, а не сущность предметной области |
| Черновик | Не моделируем | В выбранных сценариях хранение черновиков не является основной функцией системы |
| Push-уведомление | Класс | Представляет уведомление, связанное с сообщением и получателем |
| Сервис push-уведомлений | Внешняя система | Находится за пределами мессенджера и взаимодействует с ним через запросы |
| История сообщений | Атрибут/связь Чат и Сообщение | Представляется набором сообщений, связанных с чатом |
| Ошибка соединения | Не моделируем | Является исключительной ситуацией, а не самостоятельной сущностью |
