# Рефлексия

## 1. Граница системы

Системой является сам мессенджер: он отвечает за регистрацию пользователей, управление чатами, отправку и получение сообщений, а также отслеживание статуса присутствия пользователей в сети. Внешним окружением являются пользователи и внешние средства передачи данных, необходимые для взаимодействия через интернет. Граница проведена по функциональности, за которую непосредственно отвечает мессенджер.

## 2. Наиболее полезные диаграммы UML

Для мессенджера наиболее полезными будут диаграмма вариантов использования, диаграмма классов и диаграмма последовательности. Диаграмма вариантов использования показывает возможности системы и цели пользователей, диаграмма классов описывает структуру пользователей, чатов и сообщений, а диаграмма последовательности позволяет проследить процесс отправки и доставки сообщения, в том числе если получатель находится офлайн.

## 3. Раскладка PlantUML

При построении диаграмм PlantUML автоматически размещал элементы не совсем так, как хотелось: некоторые связи пересекались, а элементы располагались слишком близко друг к другу. Для улучшения читаемости использовались направление диаграммы, группировка элементов и настройка общего стиля через файл `_style.puml`.
