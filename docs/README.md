# Описание системы

Мессенджер — это информационная система, предназначенная для обмена сообщениями между пользователями через интернет. Системой пользуются зарегистрированные пользователи, которые хотят общаться друг с другом в режиме реального времени. Пользователи могут создавать личные и групповые чаты, отправлять и получать сообщения. Система позволяет отслеживать присутствие пользователей в сети и отображать их статус (онлайн или офлайн). Если получатель находится офлайн, отправленные ему сообщения сохраняются в системе до момента его повторного подключения. После возвращения пользователя в сеть система обеспечивает доставку накопленных сообщений. Основная задача мессенджера — обеспечить удобный и надёжный обмен сообщениями между пользователями, независимо от их текущего статуса подключения.
