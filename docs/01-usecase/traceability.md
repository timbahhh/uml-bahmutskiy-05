# Трассировка требований FURPS+

| Вариант использования | Функциональное требование | Нефункциональное требование (FURPS+) |
|---|---|---|
| ВИ-01. Зарегистрироваться | Система должна создавать учётную запись пользователя после ввода необходимых данных | **Security:** пароли должны храниться в защищённом виде и не сохраняться в открытом виде |
| ВИ-02. Войти в систему | Система должна проверять учётные данные пользователя и предоставлять доступ к его аккаунту | **Security:** система должна блокировать вход после 5 неудачных попыток на 10 минут |
| ВИ-03. Создать личный чат | Система должна создавать чат между двумя пользователями | **Performance:** создание чата должно занимать не более 2 секунд при штатной нагрузке |
| ВИ-04. Создать групповой чат | Система должна создавать групповой чат и добавлять в него выбранных участников | **Usability:** создание группового чата должно выполняться не более чем за 5 действий пользователя |
| ВИ-05. Отправить сообщение | Система должна сохранять сообщение и передавать его участникам чата | **Reliability:** система должна подтверждать сохранение сообщения до передачи его получателям |
| ВИ-06. Проверить участие в чате | Система должна проверять наличие у пользователя доступа к выбранному чату | **Security:** пользователь не должен получать доступ к сообщениям чата, участником которого он не является |
| ВИ-07. Просмотреть статус пользователя | Система должна отображать актуальный статус пользователя: онлайн или офлайн | **Performance:** изменение статуса должно отображаться другим пользователям не позднее чем через 3 секунды |
| ВИ-08. Получить сообщения | Система должна передавать пользователю новые сообщения из его чатов | **Reliability:** система не должна терять сохранённые сообщения при временном отключении пользователя |
| ВИ-09. Сохранить сообщение для офлайн-получателя | Система должна сохранять сообщения, которые не удалось доставить из-за отсутствия подключения получателя | **Reliability:** сохранённые сообщения должны оставаться доступными для доставки после повторного подключения пользователя |
| ВИ-10. Отправить push-уведомление | Система должна передавать внешнему сервису запрос на уведомление о новом сообщении | **Performance:** запрос на отправку уведомления должен передаваться внешнему сервису не позднее чем через 2 секунды после сохранения сообщения |
