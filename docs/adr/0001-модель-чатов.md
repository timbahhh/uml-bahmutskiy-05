# ADR-0001. Разделение личных и групповых чатов на отдельные классы

**Дата:** 2026-09-28
**Статус:** принято

## Контекст

Мессенджер поддерживает личные и групповые чаты. У этих видов чатов разные правила: личный чат предназначен для общения двух пользователей, а групповой чат может включать нескольких участников. Необходимо выбрать способ представления этих различий в доменной модели.

## Рассмотренные варианты

1. Использовать один класс «Чат» с атрибутом типа чата и дополнительными проверками для каждого вида.
2. Использовать абстрактный класс «Чат» и два наследника: «ЛичныйЧат» и «ГрупповойЧат».

## Решение

Выбран вариант 2. Общие свойства и поведение находятся в классе «Чат», а особенности личных и групповых чатов представлены отдельными классами.

## Последствия

**Плюсы:** модель явно отражает различия между видами чатов; проще добавлять специфичные правила и операции.

**Минусы:** появляется дополнительная структура классов; при добавлении нового вида чата потребуется расширить иерархию.

**Что станет неверным, если решение пересмотреть:** диаграмма классов, объектная диаграмма и сценарии создания личных и групповых чатов.
