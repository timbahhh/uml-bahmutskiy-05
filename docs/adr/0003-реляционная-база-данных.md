# ADR-0003. Использование PostgreSQL для хранения данных

**Дата:** 2026-09-28
**Статус:** принято

## Контекст

Мессенджеру необходимо хранить учётные записи пользователей, чаты, участие пользователей в чатах и сообщения. Между этими сущностями существуют связи, целостность которых должна поддерживаться при изменении данных.

## Рассмотренные варианты

1. Использовать PostgreSQL — реляционную систему управления базами данных с поддержкой транзакций и внешних ключей.
2. Использовать MongoDB — документную систему хранения данных, позволяющую хранить связанные данные в документах.

## Решение

Выбран вариант 1 — PostgreSQL. Данные пользователей, чатов, участия и сообщений хранятся в связанных таблицах.

## Последствия

**Плюсы:** поддерживается ссылочная целостность; доступны транзакции; структура хранения соответствует реляционной доменной модели.

**Минусы:** необходимо проектировать таблицы и связи; изменение структуры данных требует миграций.

**Что станет неверным, если решение пересмотреть:** диаграмма C4 Container, описание архитектуры, модель хранения данных и компоненты доступа к базе данных.
